# Landing Page com Python e Flask

Projeto simples de landing page criado com Python, Flask, HTML e CSS.

## Tecnologias usadas

- Python
- Flask
- HTML
- CSS
- Git
- GitHub
- Vercel

## Como rodar localmente

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
